## Climagold QC — v1.3 preview
Aplikacja Android do dokumentacji fotograficznej kontroli jakości: [opis i instrukcja](climagold-qc/README.md).

Odczyt oznaczeń C/K/IEW/RIEW z identyfikatorem, dwa odczyty offline i podpowiedzi do sprawdzenia; nowy interfejs i import zdjęć. Android 10+. [Pobierz APK v1.3 preview](releases/Climagold-QC-v1.3-preview.apk?raw=true).

APK v1.3 ma inny podpis niż historyczny plik v1.1 i nie zainstaluje się jako jego aktualizacja. Przed ewentualną zmianą instalacji zakończ bieżącą serię i zabezpiecz zdjęcia; nie odinstalowuj aplikacji z otwartą sesją.

[Historyczny APK v1.1 preview](releases/Climagold-QC-v1.1-preview.apk) nie zawiera nowych funkcji.
