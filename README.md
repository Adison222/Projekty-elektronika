## Climagold QC — v1.3 preview
Aplikacja Android do dokumentacji fotograficznej kontroli jakości: [opis i instrukcja](climagold-qc/README.md).

Odczyt oznaczeń C/K/IEW/RIEW z identyfikatorem, dwa odczyty offline i podpowiedzi do sprawdzenia; nowy interfejs i import zdjęć. Android 10+. APK v1.3 jest dostępny jako artefakt udanej [kompilacji GitHub Actions](https://github.com/Adison222/Projekty-elektronika/actions).

[Historyczny APK v1.1 preview](releases/Climagold-QC-v1.1-preview.apk) nie zawiera nowych funkcji.
