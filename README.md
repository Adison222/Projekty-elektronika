## Climagold QC — v1.4 preview
Aplikacja Android do dokumentacji fotograficznej kontroli jakości: [opis i instrukcja](climagold-qc/README.md).

Automatyczne zakończenie serii po powrocie z aparatu lub blokadzie ekranu, wznowienie ostatniej sesji, odczyt C/K/IEW/RIEW i import zdjęć. Android 10+. [Pobierz APK v1.4 preview](releases/Climagold-QC-v1.4-preview.apk?raw=true).

APK v1.4 ma ten sam podpis co udostępniony APK v1.3 i można go zainstalować jako aktualizację v1.3. Podpis różni się od historycznego pliku v1.1. Przed ewentualną zmianą instalacji zakończ bieżącą serię i zabezpiecz zdjęcia; nie odinstalowuj aplikacji z otwartą sesją.

[Historyczny APK v1.1 preview](releases/Climagold-QC-v1.1-preview.apk) nie zawiera nowych funkcji.
