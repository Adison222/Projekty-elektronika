## Climagold QC — v1.2 preview
Aplikacja Android do dokumentacji fotograficznej kontroli jakości: [opis i instrukcja](climagold-qc/README.md).

Nowy interfejs, import zdjęć do OCR, numery ogólne i opcjonalny odczyt pisma ręcznego. Android 10+. APK v1.2 jest dostępny jako artefakt udanej [kompilacji GitHub Actions](https://github.com/Adison222/Projekty-elektronika/actions).

[Historyczny APK v1.1 preview](releases/Climagold-QC-v1.1-preview.apk) nie zawiera nowych funkcji.
